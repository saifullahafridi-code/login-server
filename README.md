# Simple Login Server

A lightweight Express.js server that handles a basic login system with a clean HTML frontend.

## 🚀 Features

- Express.js server setup
- Static file serving
- Login form handling
- Form data processing
- Clean and simple architecture

## 📋 Prerequisites

Before you begin, ensure you have installed:

- [Node.js](https://nodejs.org/) (version 18 or higher)
- npm (comes with Node.js)

## 🛠️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/saifullahafridi-code/login-server.git
   ```

2. Navigate to the project directory:

   ```bash
   cd login-server
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

## 🚀 Running the Application

1. Start the server:

   ```bash
   npm start
   ```

2. Open your web browser and visit:

   ```plaintext
   http://localhost:3000
   ```

The server will be running on port 3000 by default.

## 💻 Tech Stack

- [Express.js](https://expressjs.com/) - Fast, unopinionated, minimalist web framework for Node.js
- HTML - Frontend markup
- Node.js - Runtime environment

## 📝 API Endpoints

- `GET /` - Serves the static login page
- `POST /login` - Handles login form submissions
